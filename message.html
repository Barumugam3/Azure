Tips for perfect EN/AR messages

  • Prefer this editor’s output over manual styling. It adds semantic dir="auto" which many inboxes and browsers respect.
  • If mixed numbers/punctuation look wrong next to Arabic, insert invisible direction marks: LRM (‎) or RLM (‏).
  • Use monospaced references carefully (IDs like ABC-123). If they appear mirrored in Arabic context, place an LRM before and after.
  • When sending via APIs, keep the <meta charset="utf-8"> and ensure your transport is UTF‑8; avoid legacy encodings.
  • In HTML emails, set container style: white-space: pre-wrap; to preserve user line breaks.
